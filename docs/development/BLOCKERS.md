# BLOCKERS — 사용자 결정·외부 조건이 필요한 항목

> 마지막 갱신: 2026-10-15(감사 반영). 해결되면 지우지 말고 "해결" 열을 채운다.

| ID | 무엇이 막혔나 | 왜 | 필요한 것 | 해결 |
|---|---|---|---|---|
| B-01 | GitHub Pages 실제 배포 | 외부 공개는 승인 필요(지침, ADR-018) | 저장소 이름·공개 여부·push 승인 | — |
| B-02 | public 빌드에 담을 콘텐츠 | AI 생성 콘텐츠 자동 게시 금지(ADR-017). 지금 public 빌드는 승인된 Claim만 내보내고 Wiki는 "준비 중" | 사람 검토(시드 Claim, 대표 Wiki, atlas 요약) | — |
| B-03 | 콘텐츠 라이선스 | 공개 전에 정해야 함 | 텍스트·코드·그림 라이선스 결정(예: CC BY 4.0 / MIT) | — |
| B-04 | `~/aixon`의 git 관리 | 자동 커밋 금지 | `git init` 여부, 원격 저장소 | — |
| B-05 | `~/aixon/ss_copilot.html` | 조사 에이전트 산물로 보이나 무관한 파일 삭제 금지(I-14) | 삭제 여부 | — |
| B-06 | 식별자 검증(arXiv) CI 단계 | 네트워크 필요, CI에서는 선택 단계 | 없음(수동 실행 기록으로 대체, 2026-10-15 54/54 + 시드 13/13) | 수동 |
| B-07 | 공개 저장소 정책 | 무료 GitHub Pages는 **공개 저장소**가 필요하다. 저장소가 공개되면 public 빌드의 승인 관문(ADR-021)과 무관하게 미검토 초안(`data/`·`src/content/`의 AI 생성 콘텐츠), `docs/`, git 이력이 모두 공개된다. 같은 이유로 `ss_copilot.html`(B-05, I-14)과 `study/`(별도 요청 산출물)도 공개 대상이 될 수 있다 | 사용자 결정. 선택지: (a) 비공개 저장소 + 유료 Pages, (b) `dist-public`만 받는 별도 공개 저장소(소스는 비공개 유지), (c) 공개 저장소를 받아들이되 초안을 명시적으로 표시하고 `ss_copilot.html`·`study/`를 제외 | — |

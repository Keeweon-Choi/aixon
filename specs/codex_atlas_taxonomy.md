## 2. Multi-file loading in `tools/seedtool.py`
- `load_graph(path_or_paths)` accepts one YAML path, a list of paths, or a directory (all `*.yaml` in it, sorted). Sections are concatenated; `graph:` headers are merged (first file's id/name win; `assumed_background` lists are unioned). Duplicate ids across files → G001 as before. `graph_version` = hash of the merged canonical content (same result regardless of file order).
- CLI: `validate`, `quotes`, `plan`, `mastery` accept one or more graph paths (`nargs="+"` before the options).
- Tests in `tools/test_seedtool.py`: two-file merge validates; duplicate id across files → G001; file order does not change graph_version. Keep all existing tests green.

## 3. `tools/verify_identifiers.py` (stdlib only; the orchestrator runs it online)
- `python tools/verify_identifiers.py <graph paths...> [--cache data/cache/arxiv] [--offline] [--json]`: for every Paper with `identifiers.arxiv`, query the arXiv API (`http://export.arxiv.org/api/query?id_list=<comma-separated ids>&max_results=100`, at most 50 ids per request, ≥ 3 s between requests, UA "aixon-verify/0.1"), cache raw Atom responses, parse with `xml.etree.ElementTree`, and compare normalized titles (NFKC, lowercase, strip punctuation and whitespace runs, `$…$` math removed) between YAML and arXiv. Also report the arXiv v1 published date vs `earliest_public_date` (flag if the month differs).
- Output per paper: `{paper, arxiv, status: match|title_mismatch|not_found|error, arxiv_title, yaml_title, arxiv_published, date_flag}`; exit 1 if any mismatch/not_found.
- `--write-checked` option: for matches, set `metadata_checked.arxiv = <today>` in the YAML file **by editing only that key** (preserve comments/order — do it with a careful line-based edit, not by re-dumping the YAML), and write a report JSON to `data/cache/arxiv/report.json`.
- Unit test (no network): a saved minimal Atom fixture `tools/fixtures/arxiv_sample.xml` with two entries; test match, mismatch, not-found and the normalizer.

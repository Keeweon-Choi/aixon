## Hard requirements
1. **Static only**: `astro build` output in `dist/`, no server runtime, no DB, no LLM. React only as islands (`client:visible`/`client:idle`).
2. Config via env: `AIXON_BASE` (default `/`), `AIXON_SITE` (default `http://localhost:4321`), `AIXON_BUILD` (`preview` default | `public`), `AIXON_GRAPH` (comma-separated YAML paths; default `data/seed/seed_graph.yaml,data/graph/atlas.yaml`, missing files skipped with a build warning), `AIXON_WIKI_DIR` (default `src/content/wiki`). `trailingSlash: "always"`, `build.format: "directory"`. Every internal link goes through one `url()` helper that prefixes `import.meta.env.BASE_URL`.
3. **Graph loader** `src/lib/graph/` (TypeScript, build time): read the YAML files (`yaml` package), merge sections like seedtool (duplicate id → throw), index entities/claims/sources, derive: field tree (`parents`), memberships (`fields`), claims by subject/object, intro year (min earliest_public_date of papers with a verified INTRODUCES to the entity), prerequisites by dimension (verified PREREQUISITE_OF / RECOMMENDED_BEFORE, 02 §6.1). Apply the **build-mode filter** (WIKI_CONTENT_ARCHITECTURE §4): in `public`, keep only claims with `review.decision == "approve"`, hide AI summaries without `summary_review` approve (show name + "준비 중"), keep only wiki docs with `status: published`. In `preview`, keep all non-rejected/non-deprecated claims with status badges. Never show `rejected`/`deprecated` claims except on their own claim page (history).
4. **Wiki**: Astro content collection `wiki` with a glob loader at `AIXON_WIKI_DIR` and a zod schema implementing CONTENT_SCHEMA §2 exactly (enums, required fields, regexes). MDX with remark-math + rehype-katex (KaTeX CSS from `node_modules/katex/dist/katex.min.css` bundled locally, never from a CDN). Components from CONTENT_SCHEMA §3 in `src/components/wiki/`: `Section`, `Level`, `ConceptLink`, `Cite`, `Callout`, `Figure`, and the island `SoftmaxTemperatureLab`. `ConceptLink`/`Cite` resolve against the graph at build time and **throw** on unknown ids (so the build fails). The wiki page renders: status banner (draft → "검토 전 초안 · AI 작성" when `ai_generated`), level switcher (직관 / 기초 / 심화 — client-side toggle that hides `<Level>`/`<Section>` content above the chosen level; default 기초; works without JS by showing everything), table of contents from `<Section>` titles, auto-generated **관련 개념** (verified prerequisites by dimension, PART_OF parts/wholes, IS_A, related) and **참고문헌과 근거** (every `<Cite>` number → Source title/version/link and, for claims, a link to the claim page).
5. **Pages** (CONTENT_SCHEMA §6 URLs, WIKI_CONTENT_ARCHITECTURE §7 table): `/` (top fields with counts, search box, coverage summary, featured wiki), `/atlas/`, `/fields/[slug]/`, `/e/[type]/[slug]/` for every entity type, `/wiki/[slug]/`, `/claims/[slug]/` (Evidence Inspector: natural-language statement per predicate, predicate definition from 02 §8, status + verification + human review state, confidence as ordinal text, evidence list with quote, locator, stance, Source version and a deep link `fulltext_url#:~:text=<encoded first words>`), `/trace/` (research lineage of verified research claims), `/coverage/` (per field: entity count, wiki status counts, verified/reviewed claim counts; list of missing wiki for KUs), `/search/` (Pagefind UI + node quick search), `/about/` (methodology, statuses, AI-content policy — short, from the docs), `404`. Korean UI text. `<html lang="ko">`, unique `<title>` and `<meta name="description">` per page, canonical link, Open Graph title/description.
6. **Islands** (`src/islands/`): `GraphView` with modes `atlas` (field hierarchy, progressive expansion: start at top fields; click a field to expand its subfields/members; node panel with summary, type, status, links), `local` (depth-1 neighborhood on entity pages), `trace` (x = intro year, lanes by field, research predicates only, edge style per 05 §4.3, click edge → claim page). React Flow + dagre (`atlas`/`local` top-to-bottom layered layout, `trace` custom x positions). Visible node cap 80 with a "+N개 더" node. Keyboard: nodes focusable with aria-label "type name status"; edges not tab stops. Every graph view has a **목록 보기** toggle rendering the same nodes/edges as an HTML table (also used on phones < 700 px wide by default). Islands read `graph.json` from `url("graph.json")`. Filters on atlas: node type checkboxes, "검증된 관계만" toggle. URL hash `#node=<id>` selects a node (link targets from entity pages: `/atlas/#node=<id>`). Note: only plain `#` anchors are guaranteed — use `#node-<encoded id>` (letters, digits, `-`, `.`, `_`, `~`), encoding `:` as `~`.
7. **Lab** `SoftmaxTemperatureLab` per 05 §5.3: pure TS core in `src/lib/lab/` (`mulberry32`, `gaussian` = Box–Muller cos branch with `u1 = 1 - r()`, `softmax(z, T)` with max-subtraction, `entropy`, `sdpaStats(dk, nKeys, samples, scaled, seed)` = exactly tools/gen_lab_fixtures.py, `jacobianFro`). UI: mode A temperature (5 editable logits as number inputs, T slider 0.05–5 log scale, probability bars with numeric labels to 4 decimals, max-prob & entropy readouts, live formula with KaTeX), mode B scaled dot-product (d_k select {1,4,16,64,256,1024}, scaling toggle, seed input, n_keys 8, 1000 samples computed on demand with a "계산" button, readouts: Var(q·k), mean max weight, mean Jacobian norm). Every displayed number has a stable `data-testid` (e.g. `prob-0`…`prob-4`, `max-prob`, `entropy`, `var-qk`, `mean-max-weight`, `jac`). Prediction quiz: show the lab_prediction items attached to `lab:softmax-temperature` in the graph (prompt, choices/number input, check answer client-side against the item answer/tolerance, show rationale). No persistence (P2).
8. **Search**: build-time `node-index.json`; header quick-search box (substring match on name/aliases/id, case-insensitive, works for 2-character Korean queries, top 8 results, keyboard navigable). After `astro build` run `pagefind --site dist` (index only `<main data-pagefind-body>`); `/search/` loads `pagefind/pagefind-ui.js` with the base path.
9. **SEO**: `@astrojs/sitemap` (respects base), `robots.txt` (preview build: `Disallow: /`; public build: allow + sitemap URL), meta per page as above.
